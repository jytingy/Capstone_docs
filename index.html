Overview

What is LagLens?

LagLens is a stock analysis application designed to help users interested in stocks to make smarter and more profitable decisions based off of data-driven insights.

The platform combines real-time market data with analytical simulations and data into a single, interactive interface.

Key features

Stocks Display Dashboard

Interactive dashboard with numerous informative features.

Analysis Tools

Dashboard of comprehensive graphs and simulations to provide informative insights on stock trend and relationships.

DeltaLag Model

Machine learning model for predictive analytics.

Diversification Portfolio

Identifies quality picks and most optimal stock options to diversify a user's portfolio.

Who is it for?

  • Retail investors researching individual stocks
  • Financial analysts running comparative market research
  • Beginners looking to learn about stock analysis

Getting started

Quick start

Get up and running with LagLens in under a minute.

You'll need an account before proceeding.

Steps

1

Create or sign in to an account

Sign in with your email and password, or create a new account with an valid email.

2

Keep track of stocks

Use the search bar at the top to find a specificticker (e.g., AAPL, TSLA). Click on individual stocks to view price trends.

3

Run stock analysis

In the analysis tab, view various available analytical graphs to learn about specific tickers and run lead-lag analysis.

4

Play around with our model feature.

Analyze a portfolio of stocks using our predictive model.

5

Diversify a stock portfolio

Use our diversification tool to help identify the optimal stock options.

Features

Stock Dashboard

Simple dashboard that displays a list of stocks and their price charts.

Chart panel

  • Switch between timeframes: 1D, 5D, 1W, 1M, 6M, 1Y, 5Y
  • Click into specific stocks to show OHCLV data
  • See year by performance graph along with fundamental data of specific stock
  • Can favorite and search/filter for certain stocks

Features

Analysis Dashboard

Our application features multiple analysis tools to provide comprehensive, data-driven insights.

Analysis Features

Analysis TypeWhat it shows
Year-by-year Price Performance GraphA year-over-year normalized price performance chart for AAPL comparing 2024, 2025, and 2026, with a fundamental data panel on the right showing key metrics like market cap and P/E ratio.
Lead-Lag Hypothesis GraphAn interactive tool that analyzes two stocks to detect which one leads and which follows, displaying key lag metrics and a normalized price chart to visualize the relationship.
Lead-Lag Networks GraphAn interactive network graph that maps lead-lag relationships across multiple stocks, where node color indicates leadership tendency and node size reflects connections, with a detail panel showing a selected stock's leads, follows, and centrality metrics.
Monte-Carlo SimulationSimulation that runs a Monte-Carlo simulation to show projected price path of a stock within a cone of potential prices.

Glossary

TermDefinition
CovarianceThe measure of joint variability between two random variables, indicating whether they move together (positive) or in opposite directions (negative).
BenchmarkA reference index or ticker used as the comparison point in lag detection.
Rolling windowThe historical time range used in a lag analysis (e.g., 60 days).
OHLCVOpen, High, Close, Low, Volume (usually pertaining to end-of-day stock data for a particular stock).
Russell 3000An index that measures the performance of the largest 3000 US companies which represents approximately 98% of the investable US equity market.
S&P 500Standard and Poor’s 500 is a stock market index tracking the stock performance of 500 leading companies listed on stock exchanges in the United States.
Distance CorrelationA statistical measure of dependence between two random vectors (variables) that detects both linear and non-linear relationships, unlike Pearson's correlation which only finds linear ones; it's zero if and only if the variables are truly independent, ranging from 0 to 1, and is calculated using Euclidean distances between sample points after a double-centering process, providing deeper insights into complex data.
TickerA unique symbol identifying a publicly traded company (e.g., AAPL for Apple).
Lead-Lag RelationshipA relationship between two time series where one, 'leader', tends to move before the other, the 'lagger’, suggesting a predictive relationship.
